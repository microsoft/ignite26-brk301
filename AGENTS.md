# Contributor instructions

Work on a feature branch and open a pull request. Do not push to the default
branch or merge without the maintainer's explicit approval.

The two demos intentionally have separate Python environments. Run commands from
the relevant demo directory. Preserve customer-service property/date scoping,
both payroll agent identities, authenticated human approval, and exactly-once
ledger effects. Fabric is an analytical projection, not the financial authority.

Keep environment files, deployment outputs, agent bindings, mailbox/chat evidence,
tokens, generated packages, and browser profiles out of Git. Do not deploy,
reset financial state, hire agents, or send messages as part of local validation.
Do not claim a live deployment was verified from offline tests.

Read the microsoft-foundry skill before changing Microsoft Foundry agent code.
Keep both customer-service instruction copies synchronized.
