# Support

This repository is an Ignite BRK301 conference sample, provided as-is. It is not
a supported production banking or hotel-management product.

Use this repository's GitHub Issues for sample bugs, documentation corrections,
and questions. Search existing issues first and include the affected demo,
commit, command, and a minimal reproduction. Do not include credentials, tenant
bindings, private messages, or guest data.

For security reports, follow [SECURITY.md](SECURITY.md) rather than posting a
public issue. Support for underlying Azure, Microsoft Fabric, Microsoft 365,
and Agent 365 services follows those services' own support channels.
